Example prompts that worked有效的提示例子

“Build a reproducible 500-entry corpus of official bilingual Hong Kong street names. Use a traceable public source, record the seed and filters, classify transliteration versus semantic translation, and validate every row against the source before publishing.”
「建立 500 項可重現的香港官方雙語街道名稱語料。使用可追溯的公開來源， 記錄種子及篩選條件，分類音譯與意譯，並在發布前逐項對照來源驗證。」
“Make search and every filter update the network, treemap, heatmap, and data table together. Make chart elements clickable, save state in the URL, and check every chart count against the same filtered table.”
「讓搜尋及所有篩選同步更新網絡圖、矩形樹圖、熱圖及資料表。圖表元素必須可點擊， 狀態保存在網址，並核對每幅圖的數字是否與同一個篩選資料表一致。」

One important AI error一個重要的 AI 錯誤

After the topic changed from subtitle humor to street names, the assistant pushed the old 500-entry humor CSV into the new street-name repository. The project owner opened the file and immediately noticed that every row was about jokes rather than streets. The file was removed, and a new corpus was built from the official Transport Department dataset instead.

題目由字幕幽默改為街道名稱後，AI 助手一度把舊有的 500 項笑話語料 CSV 推送到新的街道名稱儲存庫。項目負責人打開檔案後，立即發現每一列都是笑話而非街道。 該檔案其後被移除，並改以運輸署官方資料重建語料。

The lesson was concrete: a correct-looking file still needs a topic check, source check, and row-level preview. Automated validation alone cannot catch every wrong-context decision.

這次錯誤說明：檔案即使格式正確，仍需檢查題目、來源及實際列值。 自動驗證不能取代對整體語境的判斷。
